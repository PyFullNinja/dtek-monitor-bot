# DTEK Monitor Bot

Telegram-бот для получения графика отключений электроэнергии DTEK по указанному адресу. Бот автоматически открывает сайт DTEK через Playwright, получает актуальный график и отправляет пользователю интервалы отключений.

## Требования

- Python 3.11 или новее
- Telegram-бот, созданный через [@BotFather](https://t.me/BotFather)
- ID администратора Telegram
- Доступ в интернет

## Установка

1. Откройте каталог проекта:

   ```bash
   cd dtek-monitor-bot
   ```

2. Создайте виртуальное окружение:

   ```bash
   python3 -m venv .venv
   ```

3. Активируйте его:

   **Linux/macOS:**

   ```bash
   source .venv/bin/activate
   ```

   **Windows PowerShell:**

   ```powershell
   .venv\Scripts\Activate.ps1
   ```

4. Установите Python-зависимости:

   ```bash
   python -m pip install --upgrade pip
   pip install -r requirements.txt
   ```

5. Установите браузер Chromium для Playwright:

   ```bash
   playwright install chromium
   ```

   На Linux при необходимости также установите системные зависимости:

   ```bash
   playwright install-deps chromium
   ```

## Настройка

В каталоге проекта создайте файл `.env`:

```env
API_TOKEN=123456789:ваш_токен_от_BotFather
ADMIN_ID=123456789
```

- `API_TOKEN` — токен Telegram-бота от [@BotFather](https://t.me/BotFather).
- `ADMIN_ID` — числовой Telegram ID администратора, который будет подтверждать заявки пользователей.

Не публикуйте файл `.env`: он уже добавлен в `.gitignore`.

## Запуск

После активации виртуального окружения выполните:

```bash
python bot.py
```

При успешном запуске в консоли появится сообщение `🤖 Бот запущен`. Для остановки нажмите `Ctrl+C`.

## Как пользоваться ботом

1. Откройте бота и отправьте `/start`.
2. Новый пользователь отправляет адрес в свободной форме, например:

   ```text
   Днепр, Набережная Победы, 50а
   ```

3. Администратор получает заявку и нажимает **«Дать доступ»**.
4. Администратор последовательно вводит URL сайта DTEK, город, улицу и номер дома, поправляет формат адреса сверяясь с сайтом DTEK.
5. После подтверждения пользователь снова отправляет `/start` и получает график.
6. Кнопка **«График на завтра»** позволяет запросить график на следующий день.

По умолчанию используется URL:

```text
https://www.dtek-dnem.com.ua/ua/shutdowns
```

## Команды администратора

Команда `/stats` показывает количество пользователей, состояние очереди парсинга, количество ошибок и статистику кэша. Она доступна только пользователю с `ADMIN_ID`.

## Важные файлы

| Файл | Назначение |
| --- | --- |
| `bot.py` | Запуск Telegram-бота и обработчики сообщений |
| `config.py` | Конфигурация и переменные окружения |
| `dtek_automate.py` | Получение страницы DTEK через Playwright |
| `main.py` | Парсинг HTML-страницы в JSON |
| `database.py` | Работа с базой пользователей SQLite |
| `requirements.txt` | Python-зависимости |

Файлы `user.db`, `dtek_shutdowns.html` и `today_schedule.json` создаются или обновляются автоматически во время работы.

## Ручной запуск парсера

Если HTML-файл уже сохранён, его можно обработать отдельно:

```bash
python main.py dtek_shutdowns.html
```

Автоматизацию получения данных для конкретного адреса можно запустить так:

```bash
python dtek_automate.py \
  --city "Днепр" \
  --street "Набережная Победы" \
  --house "50а"
```

Для графика на завтра добавьте флаг `--next-day`.
