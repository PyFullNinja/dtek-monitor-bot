# DTEK Monitor Bot

Telegram-бот для отримання графіка відключень електроенергії DTEK за вказаною адресою. Бот автоматично відкриває сайт DTEK через Playwright, отримує актуальний графік і надсилає користувачеві інтервали відключень.

## Вимоги

- Python 3.11
- Telegram-бот, створений через [@BotFather](https://t.me/BotFather)
- ID адміністратора Telegram

## Встановлення

1. Клонуйте репозиторій:

   ```bash
   git clone https://github.com/PyFullNinja/dtek-monitor-bot
   cd dtek-monitor-bot
   ```

2. Створіть віртуальне середовище:

   ```bash
   python3 -m venv .venv
   ```

3. Активуйте його:

   **Linux/macOS:**

   ```bash
   source .venv/bin/activate
   ```
   Або якщо ви використовуєте fish:
   ```bash
   source .venv/bin/activate.fish
   ```

   **Windows PowerShell:**

   ```powershell
   .venv\Scripts\Activate.ps1
   ```

4. Встановіть Python-залежності:

   ```bash
   python -m pip install --upgrade pip
   pip install -r requirements.txt
   ```

5. Встановіть браузер Chromium для Playwright:

   ```bash
   playwright install chromium
   ```

   У Linux за потреби також встановіть системні залежності:

   ```bash
   playwright install-deps chromium
   ```

## Налаштування

У каталозі проєкту створіть файл `.env`:

```env
API_TOKEN=123456789:ваш_токен_від_BotFather
ADMIN_ID=123456789
```

- `API_TOKEN` — токен Telegram-бота від [@BotFather](https://t.me/BotFather).
- `ADMIN_ID` — числовий Telegram ID адміністратора, який підтверджуватиме заявки користувачів.

## Запуск

Після активації віртуального середовища виконайте:

```bash
python bot.py
```

У разі успішного запуску в консолі з’явиться повідомлення `🤖 Бот запущен`. Щоб зупинити бота, натисніть `Ctrl+C`.

## Як користуватися ботом

1. Відкрийте бота та надішліть `/start`.
2. Новий користувач надсилає адресу у довільній формі, наприклад:

   ```text
   Дніпро, Набережна Перемоги, 50а
   ```

3. Адміністратор отримує заявку та натискає **«Надати доступ»**.
4. Адміністратор послідовно вводить URL сайту DTEK, місто, вулицю та номер будинку, виправляючи формат адреси відповідно до сайту DTEK.
5. Після підтвердження користувач повторно надсилає `/start` і отримує графік.
6. Кнопка **«Графік на завтра»** дає змогу запросити графік на наступний день.

За замовчуванням використовується URL:

```text
https://www.dtek-dnem.com.ua/ua/shutdowns
```

## Команди адміністратора

Команда `/stats` показує кількість користувачів, стан черги парсингу, кількість помилок і статистику кешу. Вона доступна лише користувачеві з `ADMIN_ID`.

## Важливі файли

| Файл | Призначення |
| --- | --- |
| `bot.py` | Запуск Telegram-бота та обробники повідомлень |
| `config.py` | Конфігурація та змінні середовища |
| `dtek_automate.py` | Отримання сторінки DTEK через Playwright |
| `main.py` | Парсинг HTML-сторінки в JSON |
| `database.py` | Робота з базою користувачів SQLite |
| `requirements.txt` | Python-залежності |

Файли `user.db`, `dtek_shutdowns.html` і `today_schedule.json` створюються або оновлюються автоматично під час роботи.

## Ручний запуск парсера

Якщо HTML-файл уже збережено, його можна обробити окремо:

```bash
python main.py dtek_shutdowns.html
```

Автоматизацію отримання даних для конкретної адреси можна запустити так:

```bash
python dtek_automate.py \
  --city "Дніпро" \
  --street "Набережна Перемоги" \
  --house "50а"
```

Для графіка на завтра додайте прапорець `--next-day`.
